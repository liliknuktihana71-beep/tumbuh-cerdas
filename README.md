# Belajar Berdaya dan Bertumbuh

**TUMBUH CERDAS — Montessori Learning Companion**

Platform belajar publik yang membantu peserta didik Fase C (kelas V–VI) belajar melalui pengalaman nyata, eksplorasi mandiri, latihan bermakna, dan refleksi.

## Prinsip pembelajaran

- Dari benda konkret menuju gambar dan simbol abstrak.
- Aktivitas sederhana, aman, dan terjangkau.
- Belajar sesuai kesiapan dan kecepatan masing-masing.
- Menguatkan pemahaman, penerapan, refleksi, dan portofolio karya.

## Rencana pengembangan

Website ini dikembangkan bertahap, dimulai dari halaman publik dan katalog 36 unit pembelajaran. Fitur penyimpanan lintas perangkat dan akun pengguna akan dipertimbangkan pada tahap berikutnya.
